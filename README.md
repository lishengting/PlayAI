# 玩AI · PlayAI

**在你自己设备上运行大模型的多模态 AI 对话工具。**

本地推理，不联网也能用；对话内容不出本机。
支持 Windows / Linux / macOS / Android / iOS / HarmonyOS 六个平台。

## 主要功能

- **本地大模型推理** —— 在设备端直接运行量化模型，流式输出、思考链展示，
  全程离线，对话内容不出本机
- **云端模型接入** —— 兼容任意 OpenAI 协议接口，可配置多个服务商与密钥；
  也可图片、视频、音频随消息提交
- **多智能体对话** —— 单个对话可挂载多个智能体，各自独立配置模型、提示词、
  推理参数、音色与字体；支持 @ 提及路由与多轮循环讨论
- **多模态交互** —— 图片理解、视频抽帧理解、语音转文字、文字转语音、
  语音克隆、本地或云端文生图、云端文生视频
- **内容创作** —— 内置涂鸦与绘图面板，可绘制图形、添加文字并导出图片
- **数据自主** —— 对话可导出为 Markdown / JSON / 带图片的压缩包；
  支持口令加密备份与恢复、跨对话全局检索
- **多用户** —— 多用户独立数据空间，可选密码保护，用量统计不随对话删除丢失

## 快速开始

> 🚧 待补：首次启动的引导流程、模型下载步骤、云端服务配置步骤。

## 常见问题

**Q：真的不联网吗？**
本地模型模式下，除了你主动点击下载模型之外，全程不联网。
云端模型模式需要联网，但只连你自己配置的那个服务商。

**Q：我的对话会被上传吗？**
不会。本软件没有自有服务器，对话、附件、密钥全部只存在你本机。
详见[隐私政策](PRIVACY.md)。

**Q：为什么安装包这么大？**
本地推理引擎（llama.cpp、whisper.cpp、FFmpeg、ONNX Runtime 等）
需要随包分发，所以体积较大。模型文件另需下载，单个约 0.5–8 GB。

**Q：能用 GPU 加速吗？**
支持 Vulkan / Metal 的 GPU 可加速本地推理。
